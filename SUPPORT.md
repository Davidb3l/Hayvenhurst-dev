# Getting help

- **Questions, "how do I...", "is this expected?"**: open an issue with the
  **Question** template. Search [existing issues](https://github.com/Davidb3l/Hayvenhurst-dev/issues?q=is%3Aissue)
  first; someone may have asked already.
- **Bugs**: use the **Bug report** template (or the native-binary /
  performance-regression templates, which ask for the details those cases need).
- **Security vulnerabilities**: do **not** open a public issue. Follow
  [SECURITY.md](SECURITY.md) and email `dev@hayvenhurst.dev`.
- **Docs**: [Quickstart](docs/QUICKSTART.md), [Integration](docs/INTEGRATION.md)
  (Skill, MCP, HTTP API), [hayvenhurst.dev](https://hayvenhurst.dev), and
  `hayven help` for every CLI command.
- **The wider suite** (Sirius Forester, Ametrite, Catryna Wikinelli,
  PingMyBell): see [Sothis](https://github.com/Davidb3l/Sothis) and
  [getsothis.com](https://getsothis.com). Questions about how the tools work
  together are welcome here too.

Hayvenhurst is maintained by one person. Expect a reply within a few days.
When you report a problem, include `hayven --version`, your OS, and the output
of `hayven doctor`.
